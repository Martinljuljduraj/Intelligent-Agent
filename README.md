# Intelligent-Agent

In this project, we are building on an intelligent agent that is to be moved from the upper left corner of a grid to the lower right corner. 

We will first set the agent into its starting position on a 2D grid "0". The target position is indicated as "T". 

Randomly choose cells as obstacles indicated as "X". For our agent, this means moving left, right, up, and down while not moving into the randomly placed "X"'s. At the same time, we also do not want our agent to move at a point in with it already has been to prior. 

After having all that down, we will then generate a grid with a given target position which will then be run and our path will be displayed to reach the target.
